# El prompt para que Claude Code te lleve paso a paso

1. Abre **Claude Code**: en la app de Claude, la pestaña **Code**.
2. Crea una carpeta nueva para tus anuncios y ábrela en Claude Code.
3. Copia y pega esto:

```
Quiero hacer anuncios de video con el método de Anuncios Modulares (Lego).

Clona https://github.com/henderbastidasv-roofer/anuncios-modulares en una carpeta llamada "anuncios-modulares" dentro de esta carpeta, lee GUIA.md y llévame paso a paso, empezando por el paso 0. Mira los ejemplos de ejemplo-construia para entender cómo quedan.

Todo lo que hagamos (guion, teleprompter, grabación, tomas y anuncios) guárdalo en esta carpeta, no dentro de "anuncios-modulares".

No sé programar: explícame todo simple, una cosa a la vez, espera mi aprobación en cada paso, nunca me pidas contraseñas en el chat y no actives nada en Meta: todo en pausa.
```

Claude Code te va a preguntar por tu negocio y te va a ir guiando hasta tener tus anuncios en Meta, en pausa.
