# Anuncios Modulares

**Grabas una vez y armas decenas de anuncios de video**, con Claude Code.

En vez de grabar un video por anuncio, grabas **piezas** (ganchos, cuerpos y cierres) y Claude Code las mezcla como bloques de Lego. Cada combinación es un anuncio distinto, en 9:16 y 4:5, listo para subir a Meta **en pausa**.

Es el proceso exacto con el que hicimos los anuncios de **ConstruIA**, la comunidad de [Rufero Pro](https://www.skool.com/construia) para contratistas.

```
1 GANCHO + 2 o 3 CUERPOS + 1 CIERRE = un anuncio de 20 a 35 segundos
3 ganchos × 6 parejas de cuerpos × 2 cierres = 36 anuncios de una sola grabación
```

## Necesitas
- Claude Code (plan Pro o Max).
- Tu celular o una cámara, y un micrófono.
- Una cuenta de anuncios de Meta.
- Unos 15 minutos para grabar.

## Reglas

- No prometas resultados ni inventes números ni testimonios.
